# BertelsKI-Releases

Öffentlicher Download-Kanal für „Meine KI“ (`docs/` → GitHub Pages). Quellcode bleibt privat.
Sicherheitsregeln aus README.md gelten immer: keine Keys, keine Quellcodedateien, keine Interna.

## YouTube-Kanal

`youtube/` ist das Betriebshandbuch für den YouTube-Kanal. Bei jeder Aufgabe rund um Videos,
Skripte, Thumbnails, Trends oder Kanalstrategie **zuerst lesen**:
`youtube/strategie/brand-profile.md` → `youtube/strategie/content-pillars.md` →
`youtube/strategie/wettbewerb-und-suche.md` (Leit-Keyword „Lokale KI“, Lücken) → das passende
`youtube/wissen/*.md`. Neue Videos nach `youtube/produktion/skripte/_vorlage-long-form.md`,
Packaging vor dem Skript, Ideen nur mit echtem Quell-Signal in `youtube/produktion/ideen-bank.md`.
Vertonung läuft über Artlist (siehe `youtube/wissen/03-…`). Niemals Metriken erfinden, niemals
KI-Inhalte ohne Offenlegung planen. `youtube/output/` wird nicht committet. Nichts zu GitHub pushen ohne ausdrückliche Freigabe.
