# BertelsKI Updates

**Noch kein freigegebenes Update.**

Hier erscheinen künftig nur verifizierte, signierte Windows-Installationspakete. Der private Quellcode wird nicht veröffentlicht.

Der Updatefeed unter `/updates/manifest.json` wird erst nach erfolgreicher Freigabe angelegt. Ein fehlender Feed bedeutet: kein verfügbares Update.
