# Update-Feed

Noch kein Installer freigegeben. Ein `manifest.json` wird **nicht** als Platzhalter erstellt, damit der Desktop-Updater keine unvollständige Veröffentlichung für ein echtes Update hält.

Freigabebedingungen: zwei Testläufe, erfolgreicher Windows-Build, Installations- und Starttest, Ed25519-Signaturprüfung und manuelle Veröffentlichungsfreigabe.
